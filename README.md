# PAWPOP STUDIO — وكيل الإنتاج الآلي على GitHub

وكيل إنتاج ونشر قصص أنيميشن حيوانات بجودة سينمائية، يعمل **بشكل مستقل تماماً على
GitHub Actions** وينشر **فيديو جديد كل 12 ساعة** (09:00 و 21:00 بتوقيت دبي) على
قناة [PAWPOP STORIES](https://www.youtube.com/@pawpopstorieskids).

## ماذا يفعل الوكيل في كل دورة (كل 12 ساعة)

1. **فحص ذاتي** — يتحقق من المفاتيح والمحركات المتاحة فعلياً (لا بيانات وهمية أبداً).
2. **إنتاج الحلقة** — تعليق صوتي (TTS) ← إطارات مفتاحية ← مقاطع أنيميشن حقيقية
   عبر محركات متوازية (Z.ai cogvideox-3 أساسي + kie.ai احتياطي).
3. **التجميع** — مونتاج عمودي 1080×1920، انتقالات fade، موسيقى أصلية مُركّبة
   رقمياً (بدون حقوق طرف ثالث)، مؤثرات، وتخفيض صوتي تحت التعليق.
4. **بوابة جودة صادقة ≥ 8.5** — قياس فعلي: المدة، الحركة (كشف المشاهد الثابتة)،
   الصيغة، الصوت، التغطية. **قاعدة المالك: صفر مشاهد ثابتة** — أي مقطع ناقص يوقف
   التجميع ولا يُستبدل بصورة جامدة.
5. **النشر** — رفع مباشر إلى YouTube مع `publishAt` في **الموعد القادم** بدقة
   (09:00 أو 21:00 دبي) بغض النظر عن انحراف جدولة GitHub.
6. **حفظ الحالة** — يُرفع `state/state.json` إلى المستودع ليكمل الدورة التالية من
   حيث توقف.

## الإعداد (مرة واحدة — يحتاج مفتاح GitHub شخصي)

### 1) أنشئ Personal Access Token (classic)
- GitHub ← Settings ← Developer settings ← **Personal access tokens (classic)**
- Generate new token (classic) ← فعّل النطاقين: **repo** و **workflow**
- انسخ الرمز (يبدأ بـ `ghp_...`)

### 2) شغّل سكربت النشر من بيئة العمل
```bash
export GH_PAT="ghp_xxxxxxxxxxxx"     # الرمز الذي أنشأته
bash scripts/bootstrap.sh
```
يقوم السكربت تلقائياً بـ: إنشاء المستودع العام `pawpop-studio`، رفع كل المفاتيح
كمحرّة مشفّرة (Actions secrets)، رفع الحزمة الأولية لمقاطع EP004 المكتملة
(يوفّر إعادة توليدها)، ثم تشغيل أول دورة يدوياً.

### 3) المفاتيح المطلوبة (تُرفع كأسرار مشفّرة — لا تُكتب في الكود أبداً)
| السر | الاستخدام |
|---|---|
| `ZAI_BASE_URL` `ZAI_API_KEY` `ZAI_CHAT_ID` `ZAI_USER_ID` `ZAI_TOKEN` | ENGINE-A + تعليق صوتي + كتابة القصص + الإطارات المفتاحية |
| `KIE_API_KEY` | محرك احتياطي (kie.ai) |
| `PIXVERSE_API_KEY | استضافة الصور للمحرك الاحتياطي |
| `YT_CLIENT_ID` `YT_CLIENT_SECRET` `YT_REFRESH_TOKEN` `YT_CHANNEL_ID` | الرفع إلى YouTube |

## لماذا يستحيل كشف المفاتيح؟
- الأسرار تُخزَّن عبر GitHub Actions Secrets (مشفّرة، لا تظهر في السجلات).
- الكود لا يطبع أي مفتاح، والسجلات تُظهر حالات النجاح/الفشل فقط.

## حدود معروفة (بتعارض صفر مع الأمانة)
- **المستودع يجب أن يكون عاماً (Public)**: دقائق Actions المجانية غير محدودة
  للمستودعات العامة، أما الخاصة فسقفها 2000 دقيقة شهرياً — لا تكفي دورتَي
  إنتاج (~3 ساعات لكل حلقة). الأسرار تبقى مشفّرة ولا تظهر في السجلات.
- YouTube: نطاق الرفع فقط — لا يمكن حذف فيديو أو تعديل وصف قديم.
- تحليلات القناة تحتاج نطاق `yt-analytics.readonly` غير ممنوح بعد.
- رمز OAuth في وضع Testing ينتهي تقريباً 2026-11-28 — يحتاج تجديداً من المالك
  (أو نقل التطبيق خارج Testing).
- جدولة GitHub قد تتأخر دقائق؛ وقت النشر الفعلي محمي بـ `publishAt`.
