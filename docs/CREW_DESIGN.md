## كيف يتعاونون (بروتوكول اليد)

سلسلة الإنتاج القياسية للحلقة الواحدة:

```
المخرج → وحدة التحريك → مراقب الجودة → المونتير → مراقب الجودة → الناشر → أمين الأرشيف
```

- **لوحة المهام** `crew_board.json` في مجلد كل حلقة: كل مهمة تُسجَّل بمعرّف
  فريد، وحالة، ومحرك، وملف ناتج فعلي. لا وكيل يمكنه ادعاء عمل بلا ملف حقيقي.
- **الاستلام الذري**: مهمة واحدة يلتقطها وكيل واحد فقط (منع التكرار).
- **سجل اليد**: كل تسليم بين وكيلين يُدوَّن (من → إلى، الناتج، الملاحظة).
- **حلقة الرفض**: إذا رفض مراقب الجودة مقطعاً (جامد/قصير/تالف) تعود المهمة
  إلى وحدة التحريك تلقائياً — حتى 3 محاولات، وبعدها تُصعَّد للمنتج التنفيذي.

## قواعد الفريق غير القابلة للتفاوض

1. **صفر مشاهد ثابتة**: أي مقطع لا يجتاز قياس الحركة (فرق الفريمات) يُرفض —
   لا يُستبدل أبداً بصورة جامدة، حتى لو تأخرت الحلقة.
2. **لا نشر ناقص أبداً**: الحلقة لا تُجمَّع ولا تُرفع إلا باكتمال كل المقاطع.
3. **أمانة مطلقة**: كل رقم في التقارير يأتي من قياس فعلي أو API — لا بيانات
   وهمية ولا نتائج متفائلة مرسَلة.
4. **المفاتيح لا تُطبع أبداً**: تُقرأ من `secrets/` بصلاحيات 0600.

## بوابة الحركة (السلاح ضد الصور الثابتة) — `qc_motion.py`

القياس الفعلي: 9 فريمات موزعة على المقطع → فرق إضاءة متوسط بين كل فريمين
متجاورين (مقياس 0-255):
- كل أزواج الفروق < 0.35 **أو** المتوسط < 0.60 ⇒ `STATIC-BLOCK` (مرفوض)
- مثال حقيقي من اليوم: K08_guard ⇒ أزواج `[8.5, 12.8, 12.9, 9.8, 8.0, 8.5, 6.4]`
  متوسط 9.56 ⇒ `MOTION-OK` (حركة حقيقية قوية)
